# Travel Map 專案構想

## 核心目標
建立個人互動式旅遊地圖與旅行手帳，從世界視角一路探索到城市街道及景點。

## 使用者流程
1. 在地圖搜尋國家、城市、車站或景點。
2. 放大至城市層級，查看道路、街道名稱及可用的 POI 地標標籤。
3. 點擊地圖任意位置新增旅遊紀錄，或從搜尋結果定位後新增。
4. 指定「去過、想去、計畫中」，填寫日期、照片網址及心得。
5. 透過足跡版圖、旅行時間軸、照片牆回顧旅程。
6. 使用 JSON 匯出／匯入備份。

## 主要功能
- 世界／城市／街區多層級地圖瀏覽
- 地點搜尋與定位（Nominatim）
- 旅遊標記、狀態、卡片管理
- 國家統計、時間軸、照片牆
- LocalStorage 自動儲存、JSON 備份

## 技術
原生 HTML、CSS、JavaScript；自製 Web Mercator 瓦片地圖引擎；CARTO Positron 圖磚，失敗時切換 OpenStreetMap 標準圖磚；Nominatim 地點搜尋。
